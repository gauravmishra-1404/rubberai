# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep disagreements about the
code and not the person, and do not harass anyone. This applies in issues,
pull requests, discussions and anywhere else the project is represented.

To report behaviour that breaks this, use GitHub's private vulnerability
reporting form on this repository (it reaches only the maintainer) or the
contact on the maintainer's GitHub profile. Reports are handled privately.
